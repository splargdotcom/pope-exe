**Official Discordian Ordination Terminal v23.5**

POPE.EXE is a small interactive browser toy inspired by Discordianism. On arrival you are immediately ordained and given an appropriately improbable papal identity; from there the terminal generates doctrines, missions, schisms and other bureaucratic acts of sacred nonsense.

**Play on itch.io:** https://splarg.itch.io/pope-exe

## What it does

- Generates new sacred titles
- Issues random doctrines
- Creates rival schisms
- Assigns impossible missions
- Reveals contradictory hidden truths
- Drops clickable golden apples
- Tracks an increasingly dangerous **Greyface Compliance Level**
- Includes a clickable Sacred Chao and assorted hidden chaos

There is no conventional win state. It is an interactive novelty/terminal rather than a score-driven game.

## Run locally

Open the root `index.html` in a modern browser.

The project has no build step, but the current file loads Tailwind CSS and the VT323 font from public CDNs, so an internet connection is required for the intended presentation.
